# 프로젝트 인력 연차관리 시스템

웹 UI 기반의 프로젝트 인력 연차 및 근태/사용자 관리 프로그램입니다.

---

## 🚀 주요 기능 및 특징

### 1. 사용자 관리 (User Management) - 신규 추가 ✨
- **권한 3단계 분류**:
  1. 👑 **PM (프로젝트 매니저)** : 최고 관리자 권한 (전체 연차 승인, PM 본인 등록 시 즉시 자동 확정 및 전체 PL 공유)
  2. 🛡️ **PL (프로젝트 리더)** : 중간 관리자 권한 (소속 팀 수행원의 연차 1차 검토/승인, 본인 신청 시 PM에게 승인 요청)
  3. 👤 **수행원 (프로젝트 팀원)** : 일반 인력 (연차 신청 시 `수행원 ➔ PL 1차 승인 ➔ PM 최종 승인` 2단계 결재 진행)
- **인력 CRUD 관리**:
  - 신규 인력 등록 (성명, 이메일, 소속 팀, 권한, 기본 연차 부여일수 설정)
  - 기존 인력 정보 수정 및 삭제 기능
  - 권한별/팀별/키워드별 실시간 검색 및 필터링
  - 권한별 인원수 요약 카드 제공 (PM 몇 명, PL 몇 명, 수행원 몇 명)

### 2. 연차 종류 지원
- **연차 (종일)** : 1.0일 차감 (단일일자 또는 기간 지정 가능)
- **오전 반차** : 0.5일 차감 (오전 시간대)
- **오후 반차** : 0.5일 차감 (오후 시간대)

### 3. 승인 워크플로우 (Approval Workflow)
- **수행원 (Member)** : 수행원 신청 ➔ **PL 1차 승인** ➔ **PM 최종 승인** ➔ 달력 확정
- **PL (프로젝트 리더)** : PL 신청 ➔ **PM 최종 승인** ➔ 달력 확정
- **PM (프로젝트 매니저)** : **등록 즉시 자동 확정** ➔ **각 팀 PL 알림함에 공유 내역 자동 발송**

### 4. 월별 연차 달력 (Monthly Calendar)
- 전체 프로젝트 인력의 연차/반차 현황을 한눈에 파악
- **시각적 구분** : 연차(보라색), 오전반차(주황색), 오후반차(청록색), 결재 진행중(점선 테두리)
- **필터링** : 소속 팀별, 연차 종류별(전체/연차/반차), 승인 상태별 필터 제공
- **날짜 클릭** : 해당 일자의 연차 인력 상세 팝업 및 바로 연차 신청 연동

### 5. 결재함 & 알림함
- **결재 대기 목록** : 현재 로그인된 계정(PL, PM)의 승인이 필요한 대기 건을 확인하고 [승인] 또는 [반려(사유 입력)] 처리
- **내 신청 내역** : 본인이 신청한 연차의 결재 단계별 진행 이력(신청 ➔ PL ➔ PM) 확인
- **알림 및 공유함** : PM 연차 등록 공유 및 결재 승인/반려 알림 수신

### 6. 인력별 연차 통계 대시보드
- 프로젝트 전체 인원 수, 오늘 휴가자 수, 당월 연차 사용일수, 결재 대기 건수 카드
- 팀원별 총 부여일수, 사용일수, 잔여 연차, 사용률 프로그레스 바 제공

### 7. 빠른 사용자 전환 (Role Switcher)
- 상단 네비게이션 바의 **[현재 사용자]** 드롭다운을 통해 등록된 사용자(PM, PL, 수행원)로 즉시 전환하여 각 권한별 승인/신청 흐름을 바로 테스트할 수 있습니다.
